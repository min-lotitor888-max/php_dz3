# Стандартизатор имени (ФИО) для интернет‑магазина

Скрипт на PHP, который стандартизирует ввод ФИО пользователя в трёх форматах, требуемых разными компонентами интернет‑магазина: полное имя, фамилия с инициалами и аббревиатура из первых букв.

## Задача

На сайте интернет‑магазина имя пользователя отображается по‑разному в разных компонентах:

- **Личный кабинет**: фамилия и инициалы — `Фамилия И.О.`
- **Корзина**: только первые буквы ФИО — `ИИИ`
- **Отправка заказа**: полное ФИО с корректным регистром — `Фамилия Имя Отчество`

Скрипт принимает ввод от пользователя и формирует три переменные в нужных форматах, корректно обрабатывая кириллицу.

## Функционал

- Запрос у пользователя фамилии, имени и отчества через CLI.
- Приведение всех слов к формату «первая буква заглавная, остальные строчные» (с учётом UTF‑8).
- Формирование:
  - `$fullName` — полное ФИО: `Иванов Иван Иванович`
  - `$surnameAndInitials` — фамилия и инициалы: `Иванов И.И.`
  - `$fio` — аббревиатура: `ИИИ`
- Корректная работа с кириллицей за счёт функций `mb_*` и установки локали.

## Требования

- PHP 7.4+ (рекомендуется 8.x)
- Включённое расширение `mbstring` (требуется для работы с многобайтовыми строками)
